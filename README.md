# Predikce tempa běžeckého závodu podle profilu trati

## Popis projektu
Cílem projektu je vytvořit program v jazyce Python, který pomůže běžcům naplánovat tempo závodu na základě výškového profilu trati a požadovaného cílového času.

Program zohlední stoupání a klesání na trase a navrhne vhodné rozložení tempa tak, aby běžec dosáhl svého cílového času.

## Funkcionalita
- Načtení trasy závodu ze souboru GPX.
- Zadání požadovaného cílového času.
- Analýza délky a výškového profilu trati.
- Výpočet doporučeného tempa pro jednotlivé úseky závodu.
- Zobrazení přehledu doporučeného tempa a předpokládaných mezičasů.
- Případné grafické znázornění průběhu závodu.

## Použité technologie
- **Programovací jazyk:** Python
- **Vstupní data:** GPX soubor obsahující trasu závodu
- **Výstup:** Textový přehled, případně graf

## Výsledek
Výsledkem bude jednoduchý nástroj, který umožní běžci lépe rozvrhnout síly během závodu s ohledem na náročnost jednotlivých úseků trati.
